# @freechess/web

Aplicación Next.js 16 de FreeChess (App Router, React 19, TypeScript estricto,
Tailwind CSS 4). Se crea en la **Fase 1** (identidad y fundación).

Contenido previsto:

- `app/` — rutas y páginas (dashboard, jugar, analizar, entrenar, aperturas,
  aprender, herramientas, estadísticas, perfil, ajustes).
- `components/` — componentes de la aplicación.
- `features/` — módulos funcionales por dominio.
- `hooks/` — hooks de React.
- `styles/` — tokens de diseño y estilos globales.
- `public/` — assets (piezas, tableros, sonidos, iconos, manifest PWA) y
  `ATTRIBUTIONS.md` con los créditos de licencias.
