# @freechess/chess-board

Componente React de tablero sobre `chessground`: temas de piezas y tablero,
coordenadas, promoción, resaltados, flechas y círculos, animaciones, soporte
táctil. Se desarrolla a partir de la **Fase 2**.

Las texturas y sets de piezas incorporados deben aparecer en
`docs/LICENSES.md` y en `apps/web/public/ATTRIBUTIONS.md`.
