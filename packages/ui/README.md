# @freechess/ui

Sistema de diseño de FreeChess: botones, entradas, diálogos, hojas, pestañas,
toasts, tarjetas, barras de evaluación, chips de temas y demás componentes
base construidos sobre los tokens de diseño (verde profundo, claro/oscuro).
Se construye a partir de la **Fase 1**.

Criterios: skill `.agents/skills/freechess-product-design`.
